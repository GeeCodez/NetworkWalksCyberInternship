# Network Works Internship

This repository contains all tasks completed during the **Network Walks Internship**, along with their related documentation and screenshots.

## Repository Structure

Each week has its own directory containing the project documentation and screenshots for that week.

```text
network-works-internship/
│
├── README.md
│
├── Week 1/
│   ├── screenshots/
│   │   ├── screenshot-1.png
│   │   ├── screenshot-2.png
│   │   └── ...
│   │
│   └── week-1-project.md
│
├── Week 2/
│   ├── screenshots/
│   │   ├── screenshot-1.png
│   │   ├── screenshot-2.png
│   │   └── ...
│   │
│   └── week-2-project.md
│
└── ...
```

## Structure

* **`README.md`** — Provides an overview of the repository.
* **`Week X/`** — Contains all work completed during a specific week.
* **`screenshots/`** — Contains screenshots evidence of completed practical tasks.
* **`week-X-project.md`** — Contains the documentation and details of the week's project.

This structure is maintained consistently for each week of the internship.
