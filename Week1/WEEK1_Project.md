# Week 1 — Virtual Machine & Network Setup

## Overview

As part of Week 1 of the Network Walkz Internship, I set up a virtual lab environment using **Oracle VirtualBox** and **Kali Linux** for practical networking exercises.

## Tasks Completed

* Installed and configured **Oracle VirtualBox**.
* Set up a **Kali Linux virtual machine**.
* Created a VirtualBox **NAT Network** named `NAT Network`.
* Configured the network using the `10.0.0.0/24` subnet.
* Configured Kali Linux with:

  * **IP Address:** `10.0.0.2`
  * **Subnet Mask:** (`/24`)
  * **Default Gateway:** `10.0.0.1`
